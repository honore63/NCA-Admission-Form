# NCA Admission Form

## Overview
A modern, user‑friendly web application for managing new student registrations for the National College of Arts (NCA). This platform streamlines the admission process, allowing prospective students to submit their details, upload required documents, and track application status in real time.

## Features
- **Responsive Design** – Works seamlessly on desktop, tablet, and mobile devices.
- **Secure Data Handling** – All submissions are stored safely with client‑side validation.
- **Admin Dashboard** – Administrators can review, approve, or reject applications.
- **Email Notifications** – Automatic email confirmations sent to applicants.
- **Progress Tracking** – Applicants can monitor the status of their application.

## Installation
```bash
# Clone the repository (if not already cloned)
git clone https://github.com/honore63/NCA-Admission-Form.git

# Navigate to the project directory
cd NCA-Admission-Form

# Open the `site` folder in a web server (e.g., using VS Code Live Server or any static server)
# No additional dependencies are required.
```

## Usage
1. Open `site/index.html` in a web browser.
2. Fill out the registration form with the required information.
3. Submit the form to receive a confirmation email.
4. Administrators can access the admin panel (details in the documentation) to manage applications.
